# Arduino Uno — удалённое управление подсветкой

Учебная система: браузер → Flask на Render → компьютер-мост → USB Serial → Arduino Uno → низковольтная подсветка.

**Важно:** Arduino Uno не имеет Wi-Fi/Ethernet. Компьютер, подключённый к Uno по USB, должен быть включён, иметь интернет и постоянно запускать `bridge.py`. Мост сам опрашивает Render по HTTPS; входящие порты на роутере открывать не требуется.

## Состав
- `web/` — Flask-сервер и веб-интерфейс.
- `bridge/` — программа-мост для компьютера.
- `arduino/lighting_control.ino` — прошивка Uno, выход D8.

## Подключение
Для теста: D8 → резистор 220–330 Ом → длинная ножка обычного светодиода; короткая ножка → GND.

Для LED-ленты применяйте подходящий логический MOSFET-модуль и отдельный блок питания нужного напряжения/тока. Общий GND блока питания и Arduino обязателен. Не подключайте ленту напрямую к D8. Не подключайте сетевые 220 В к Arduino или макетной плате.

## Загрузка скетча
Откройте `arduino/lighting_control.ino` в Arduino IDE, выберите Arduino Uno и правильный COM-порт, загрузите скетч. Скорость Serial — 9600.

## Публикация на Render
1. Создайте GitHub-репозиторий и загрузите содержимое этой папки в корень.
2. Render → New → Web Service → подключите репозиторий.
3. Root Directory: `web`
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `gunicorn app:app`
6. В Environment добавьте `AGENT_TOKEN`, `CONTROL_PIN`, `SECRET_KEY` (длинные случайные значения).
7. Разверните сервис и скопируйте URL вида `https://имя.onrender.com`.

## Запуск компьютерного моста
1. Установите Python 3.10+.
2. В командной строке откройте папку `bridge`.
3. Выполните `py -m pip install -r requirements.txt`.
4. Скопируйте `.env.example` в `.env`.
5. Укажите `API_URL` (URL Render), `AGENT_TOKEN` (тот же, что в Render), `SERIAL_PORT` (например, `COM5`).
6. Запустите `py bridge.py`. Не держите одновременно открытым Serial Monitor Arduino IDE.

## Управление
Откройте URL Render, введите `CONTROL_PIN`, нажмите «Включить» или «Выключить». Компьютер-мост и Arduino должны быть онлайн.

## Ограничения
Состояние хранится в памяти Flask-процесса и сбрасывается при перезапуске. Бесплатный Render может засыпать, первая команда после сна может задержаться. Для круглосуточной эксплуатации нужны постоянный хостинг и внешнее хранилище. Не публикуйте `.env` и секреты.
